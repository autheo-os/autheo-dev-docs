    AUTHEO / DEVELOPER DOCUMENTATION

    AUTHEO documentation

    AUTHEO brings together a settlement chain and a design for peer connectivity, distributed compute, a capacity marketplace, developer workflows and agent-assisted operations. This documentation explains each component, how they exchange intent and evidence, and which claims have implementation support.

    Publication candidate

    This documentation was reviewed on 9 October 2026. Source-backed does not mean deployment-tested. This site does not certify network availability, platform launch status, security guarantees, or regulatory approval.

    Start with the platform map

    Autheo is a layered platform: the Autheo L1 underlies everything, the Layer 0 mesh runs workloads, and DevHub deploys to it (The Autheo stack, Layer 0 mesh). It has three surfaces priced and settled in THEO: (1) DevHub, the Autheo Labs IDE toolkit with full-stack SDKs, a workflow/DAG engine and the agentic OS; (2) the Autheo app ecosystem; and (3) the compute and storage marketplace. The platform map explains how they connect, the developer journeys give a path per role, and the roadmap records what is live, source-backed or planned as of 12 October 2026.

    Choose your path

    • New to AUTHEO? Start with the orientation and architecture.
    • Application developer? Read integration preparation, then the source-backed API reference.
    • Node operator? Follow node preparation and network reference.
    • Looking for mesh, DevHub, or marketplace instructions? Read the ecosystem map, then Mesh, DevHub, Marketplace or Freddie. These design guides are not interchangeable with the implemented chain.
    • Maintaining these docs? Use contribution rules and standalone deployment.

    Understand the whole workflow

    Start with who does what, follow control, data and accounting flows, then prepare an application brief or provider review. Intended capabilities are explained without presenting planning examples as shipped commands.

    What is verified here?

    The public chain repository contains Cosmos SDK, CometBFT, and Ethermint/EVM application code. The official network repository publishes a mainnet configuration. Evidence and limits identify exact revisions. No live transaction, validator operation, or RPC availability test was performed for this documentation update.
