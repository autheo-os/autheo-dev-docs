    MCP tool reference

    Generated from code — do not edit by hand. This page is produced by scripts/gen-mcp-reference.mjs from autheo-os/autheo-MCP commit 663416577abb (package version 0.3.0a1, committed 2026-10-12) using FastMCP tools/list and resources/list introspection of autheo_mcp.server.

    The registered surface at that commit is 44 tools and 5 resources. 44 of 44 tools declare the MCP readOnlyHint annotation. A tool being registered does not mean a live Autheo service is reachable: every tool calls only the endpoints you configure (see MCP server).

    Source-backed, not live-tested

    The MCP README states the implementation was verified with local contract fixtures and MCP stdio sessions, "not proof of access to a live Autheo installation". Descriptions below are the docstrings registered in code.

    Return display-only THEO/USD data with freshness status; not settlement authority.
