    AUTHEO / DEVELOPER DOCUMENTATION

    FAQ

    What is Autheo? A Cosmos SDK / CometBFT blockchain with EVM support, plus a developer cloud (DevHub) that runs workloads on a peer-to-peer compute fabric, a resource Marketplace priced in THEO, agent tooling (Autheo MCP) and an agent trust layer (Identity and agent trust). The ecosystem overview shows how they relate.

    Is dev.autheo.com live? Partly. On 2026-10-12 the public pages (home, docs, pricing, status, blog) were served and the dashboard required sign-in. Details: DevHub → What is live today.

    What is the API base URL? Everything starts at dev.autheo.com: sign in there and create an API key. The API is currently served from https://api.shadw.cloud, a legacy hostname that answered /healthz with ok on 2026-10-12 (the live getting-started page names https://api.autheo.dev, which did not resolve that day). A self-hosted node serves the API on http://127.0.0.1:8786.

    Why do I sometimes see "shadw"? It is the earlier working name of Autheo DevHub. A few code identifiers still use it: the CLI binary shadw, its config in ~/.shadw/, SHADW_* environment variables and the legacy API host api.shadw.cloud. The product is Autheo DevHub at dev.autheo.com; the node software is called Hive.

    How do I deploy something? Sign in at dev.autheo.com, create an API key, then use shadw deploy or POST /v1/git/deploy. See DevHub.

    Can I host a game server? Yes, DevHub has game server presets (for example Team Fortress 2, Don't Starve Together, GoldenEye: Source) with a guided setup in the dashboard.

    Can my AI agent use Autheo? Yes, read-only, through the Autheo MCP server: 44 tools covering Marketplace, DevHub, chain reads, THEO display price and agent-trust inspection. It sends no transactions and was verified against local fixtures, not a live installation.

    Can an agent spend money or sign transactions? No. Neither the MCP server nor the agent trust prototype holds wallet keys, makes payments or executes transactions. Agent trust budgets are simulated DEMO units.

    Do I need to register an identity for my agent? No. Agent identities are did:key DIDs you create offline. Authority comes from a signed delegation chain back to a root DID the verifier trusts. See Identity and agent trust.

    Where is THEO priced? DevHub/Marketplace expose a THEO reference price (/api/market-reference/theo on dev.autheo.com returned JSON on 2026-10-12). The MCP tools refuse to convert with stale or unavailable prices.

    Is the code open source? It varies: Autheo MCP and the Agent Environment are MIT. DevHub's LICENSE.md is restrictive and is not MIT. Check each repository.

    Something here is wrong or out of date. Every page lists its sources in provenance.json. Open an issue or pull request on autheo-os/autheo-dev-docs; see Contributing.
